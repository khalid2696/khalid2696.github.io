# Project Title: Khalid M Jaffar's Personal Website

## Overview
This project is a personal website for Khalid M Jaffar, a PhD candidate at the University of Maryland, College Park. The website showcases his research, publications, and personal interests.

## Project Structure
The project is organized into the following directories and files:

- **assets/**: Contains all static assets including CSS, images, and JavaScript files.
  - **css/**: Stylesheets for the website.
    - `stylesheet.css`: Defines the layout, colors, fonts, and other visual aspects of the website.
  - **img/**: Images used throughout the website.
    - `favicon-16x16.png`: Favicon displayed in the browser tab.
    - `profile.png`: Main profile image.
    - `profile-fun1.png`: Alternate profile image for hover effects.
    - **teasers/**: Contains teaser images for various publications.
  - **js/**: JavaScript files for interactive features.
    - `img_hover.js`: Handles image hover effects for the profile image.

- **content/**: Contains markdown files for different sections of the website.
  - `about-me.md`: Content for the "About Me" section.
  - `contact.md`: Content for the "Contact" section.
  - `news.md`: Content for the "News" section.
  - `outline.md`: Content for the "Outline" section.
  - **publications/**: Contains markdown files for different types of publications.
    - `journal-conferences.md`: Lists journal and conference publications.
    - `workshops-posters.md`: Lists workshop papers and posters.
    - `invited-talks.md`: Lists invited talks.
  - `teaching.md`: Content for the "Teaching" section.

- **pdfs/**: Contains PDF files of various publications.

- **index.html**: The main HTML file for the website, linking to the content and templates.

- **README.md**: Documentation for the project, explaining its structure and usage.


## Usage
To run the website, open `index.html` in a web browser. You can modify the content in the markdown files located in the `content/` directory to update the website's sections. The styles can be adjusted in `assets/css/stylesheet.css`, and any JavaScript functionality can be modified in `assets/js/img_hover.js`.

## Future Updates
This project is designed to be easily modifiable. You can add new sections by creating new markdown files in the `content/` directory and corresponding HTML templates in the `templates/sections/` directory. Additionally, you can update the CSS and JavaScript files to enhance the website's appearance and functionality.
